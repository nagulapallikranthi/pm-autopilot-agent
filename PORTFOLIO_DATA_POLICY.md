# Portfolio Data Policy

## Purpose

This repository is a generic portfolio project. Every artifact must use fictional scenarios and synthetic data only.

## Prohibited content

Do not add:

- Employer, customer, employee, team, product, service, or leadership names
- Real Jira URLs, project keys, issue IDs, board IDs, sprint names, field IDs, or automation IDs
- Real users, email addresses, groups, tenant IDs, endpoints, credentials, tokens, secrets, or webhook URLs
- Internal prompts, incidents, vulnerabilities, architecture, infrastructure, or operating procedures
- Actual ticket volumes, SLA values, costs, staffing data, or performance results
- Workplace screenshots, exports, logs, reports, or copied internal documents

## Required standard

- Use synthetic input and output datasets
- Label all sample metrics as fictional or illustrative
- Keep credentials outside the repository and never commit them
- Use placeholder environment variables in example configuration
- Review file metadata and Git history before publication
- Build reusable methods rather than reproducing organization-specific workflows

- Organization: Northstar Digital

- Teams: Platform Operations, Reliability, Developer Experience
- Users: Alex Morgan, Priya Shah, Jordan Lee

All names above are fictional.
